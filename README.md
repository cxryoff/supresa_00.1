# Projeto Quiz Especial 💕

Este é um projeto de quiz interativo e divertido criado como uma surpresa especial. O projeto consiste em uma série de páginas HTML que formam uma experiência completa e envolvente.

## 🎯 Estrutura do Projeto

### Páginas Principais
- **`verificar.html`**: Página inicial de verificação com animação de carregamento
- **`senha.html`**: Página de autenticação com senha especial
- **`quiz.html`**: Quiz principal com perguntas interativas e elementos divertidos
- **`resultado.html`**: Página final com o resultado e surpresa

### Arquivos de Suporte
- **`script.js`**: Lógica JavaScript para interatividade do quiz
- **`styles.css`**: Estilos CSS responsivos e animações
- **`fundo.jpg`**: Imagem de fundo para todas as páginas
- **`image.jpg`**: Imagem especial para o resultado final

## 🚀 Como Usar

1. **Início**: Abra `verificar.html` para começar a experiência
2. **Autenticação**: Após 3 segundos, será redirecionado para inserir a senha
3. **Quiz**: Complete as perguntas do quiz (cuidado com as respostas erradas!)
4. **Resultado**: Veja a surpresa final na página de resultado

## ✨ Funcionalidades

### 🔐 Sistema de Senha
- Verificação de senha personalizada
- Feedback visual para tentativas incorretas
- Suporte a tecla Enter para confirmar

### 🎮 Quiz Interativo
- **5 perguntas** com diferentes tipos:
  - Perguntas normais com múltipla escolha
  - Perguntas "troll" que avançam automaticamente
  - Pergunta final especial com botão que "foge"
- **Sistema de progresso** visual
- **Feedback imediato** para respostas corretas/incorretas
- **Reset automático** em caso de erro

### 🎨 Design e UX
- **Design responsivo** para todos os dispositivos
- **Animações suaves** e transições
- **Tema escuro** com fundo personalizado
- **Efeitos visuais** interativos
- **Tipografia elegante** (Georgia serif)

### 🎭 Elementos Divertidos
- Botão "Não" que se move pela tela
- Perguntas com delay automático
- Animações de feedback
- Emojis e elementos visuais

## 🛠️ Tecnologias Utilizadas

- **CSS3**: Estilos modernos, Grid, Flexbox, animações
- **JavaScript**: Interatividade e lógica do quiz

## 🔧 Personalização

Para personalizar o projeto:

1. **Senha**: Altere a senha em `senha.html` e `script.js`
2. **Perguntas**: Modifique as perguntas em `quiz.html`
3. **Estilos**: Ajuste cores e fontes em `styles.css`
4. **Imagens**: Substitua `fundo.jpg` e `image.jpg`

## 📝 Notas Importantes

- Certifique-se de que as imagens `fundo.jpg` e `image.jpg` estejam no diretório raiz
- O projeto funciona melhor quando servido via servidor web (não apenas abrindo arquivos localmente)
- Todas as animações são otimizadas para performance
